cryosparc2relion-helical-coord-tools

A custom Python toolsuite for converting, reformatting, and processing cryo-EM helical/fibril particle coordinates transferred from cryoSPARC to RELION.

This toolkit addresses two major technical challenges in helical reconstruction:

1. Curvature Adaptation: Converting cryoSPARC coordinates to RELION start-end formats while segmenting flexible filaments (e.g., every 10 particles) to mitigate bending artifacts.

2. Filament ID & FSC Restoration: Re-assigning true physical filament IDs back to extracted particles using spatial KD-Tree matching and clearing _rlnRandomSubset metadata to ensure unbiased half-map assignment during gold-standard FSC estimation.

Overview of Scripts：

This repository contains three distinct Python scripts depending on your processing needs:

**c2r_helical_tool.py**: Reads csparc2star.py output, converts particle coordinates to RELION start-end format (handling Y-axis coordinate inversion), segments fibrils into 10-particle intervals, and splits the dataset into micrograph-level STAR files.

**fix_fibril_ID_reference.py**: Performs basic micrograph-level STAR file splitting without 10-particle segmentation, preserving the original cryoSPARC _rlnHelicalTubeIDs as a spatial reference library.

**fix_fibril_ID_int_rmsubset.py**: Maps extracted particles in RELION back to the reference library from fix_fibril_ID_reference.py using spatial nearest-neighbor search (scipy.spatial.KDTree). It restores continuous tube IDs and strips _rlnRandomSubset to force RELION to perform a fresh, unbiased half-map separation.

Workflow Instructions & Usage

Method 1: Coordinate Conversion with 10-Particle Fibril Segmentation (c2r_helical_tool.py).
Use this workflow to segment curved fibrils every 10 particles and convert coordinates for RELION / crYOLO usage.

Step 1: Convert cryoSPARC metadata using PyEM
Extract particle metadata from your cryoSPARC job directory (typically a 2D Classification job):

    csparc2star.py J24_020_particles.cs J24_020_particles.star

    ##J24_020_particles.cs: Input cryoSPARC .cs file from your job directory.
    ##J24_020_particles.star: Output STAR file name (customizable).

Step 2: Run coordinate conversion & segmentation
Copy c2r_helical_tool.py into your working directory, adjust the input/output path variables inside the script if needed, and execute:

      python c2r_helical_tool.py

Move the generated output folder containing cryoSPARC coordinates to your RELION project directory.

Step 3: Convert to RELION autopick STAR files
Use cryolo_boxmanager_tools.py to create RELION-compatible autopick STAR files:

     cryolo_boxmanager_tools.py createAutopick -m 'MotionCorr/job126/rawdata/*frames.mrc' -c 'your_c2r_helical_tool.py_output/*.star' -o output/

Step 4: RELION 5 Compatibility Patch
Because cryolo_boxmanager_tools.py output formats were designed for RELION 3, you must manually edit the header of the resulting autopick.star files to work with RELION 5:

Add and replace the top lines of autopick.star with the following header:

    version 50001
    data_general

    _rlnMicrographPickType            startend

    version 50001
    data_coordinate_files

---------------------------

Method 2: Fibril ID Restoration Workflow (fix_fibril_ID_reference.py & fix_fibrilID_int_rmsubset.py)
Use this workflow after extracting/classifying particles in RELION to restore physical filament continuity and reset half-map subsets.

Step 1: Generate reference STAR files per micrograph
Run fix_fibril_ID_reference.py using the STAR file generated by csparc2star.py in Method 1:

    python fix_fibril_ID_reference.py

    ##Input: Enter the STAR file name produced by csparc2star.py when prompted (e.g., J24_020_particles.star).

Output: Generates a folder named <input_filename>_csfID_output/ containing individual micrograph STAR files with original cryoSPARC Fiber IDs.

Step 2: Re-assign Fiber IDs and strip _rlnRandomSubset
Run fix_fibrilID_int_rmsubset.py by providing:

Re-extracted/selected particles.star from RELION.

Reference folder (_csfID_output) generated in Step 1.

Reference file extension (.star).

    python fix_fibrilID_int_rmsubset.py Select/job068/particles.star ../relion/J45/J45_020_particles_csfID_output/ .star

Output: Creates Select/job068/particles_updated_intID_2.star with restored physical Tube IDs and stripped _rlnRandomSubset tags. This forces RELION to perform a fresh, unbiased half-map assignment based strictly on continuous filaments.

Validation
Testing confirmed that maps reconstructed before and after this ID re-assignment exhibited a map correlation of 0.99 with a resolution difference of ~0.1 Å, validating both structural integrity and data consistency.
